# 左侧Space不是顶部Tab

2026-10-01，firstmate通过本任务006指令转达纠正：不能把顶部Tab改名当成左侧Spaces分组。

- 要求独立Space时，验收的是独立workspace及目标tab/pane的实际父子关系；中文标签相同或Tab已改名都不证明分组完成。
- 迁移已有任务须保留原terminal、原生session、进程和cwd/工作区内容，不为改分组重启或新建替身。
- 迁移前后核对稳定身份与现场，再读回新的workspace/tab/pane并同步任务meta；端点ID变化不等于原生会话变化。
- 活进程可能仍持有旧环境快照。后续控制读取已核对的任务meta新端点，不根据旧HERDR_*环境或UI焦点猜目标。
- 已审代码先按准确冻结范围提交；本类流程经验单独维护，不能混进已审实现提交。没有独立读回证据时，只说“收到迁移报告”，不冒充已验证。
