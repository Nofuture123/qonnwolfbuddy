# 执行者的产出由执行者窗口收尾

来源：Rocky 2026-09-15 纠正——README 对外重写指定 agy CLI 交互式窗口执行，主控在 agy 交付后自行用编辑工具改了三处（LICENSE、报告计数、工人示例）并直接提交推送。

- 「用 X 工具做」的指令覆盖产物的**全部修订轮**，不只第一稿。主控发现事实错误时应把修正清单发回执行者原线程（resume 原生 session），由它改、主控验收。
- 主控只做两类修改：验收结论/账本记录（本来就是主控职责）；不超过一行的纯笔误且执行者已不可用——后者也要留一行「谁改的、为什么」。
- 自己绕过执行者改产物，会剥夺使用者在窗口里看到完整过程的可见性——这正是可见 pane 派工要保护的东西。
