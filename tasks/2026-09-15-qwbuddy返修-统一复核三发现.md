## H1（致命）：删除动作前不复核，归档对象仍可与被删对象错位（TOCTOU）

**事实（主控已代码级确认）**：`bin/qwb-worktree.sh:102` 只读一次 `HEAD_OID`；随后 `:147` / `:158` 的 `git worktree remove` 与 `:166` 的 `git branch -D` **之前没有任何复核**。若在「打标签之后、删除之前」工人又在该 worktree 提交（工作区再次干净、无需 `--force`），脚本会删掉**新提交所在的 worktree**，而标签只保存了旧提交 → **新提交丢引用**。同一窗口也存在于 `--merged`（判断通过后工作区被推进）。

另：`:101` 读取分支名失败被 `|| true` 吞掉，随后回退成「任务 id 当分支名」，仍可能删除指向别处的同名分支。

**规格（核心原则：删除的正当性必须在「即将删除的那一刻」成立）**：

1. 新增一个复核函数，例如：

```bash
recheck_head() {   # 打印当前 worktree 的实际 HEAD OID；失败则返回非 0
  git -C "$WT_DIR" rev-parse HEAD 2>/dev/null
}
check_unchanged() {
  local cur
  cur="$(recheck_head)" || { echo "错误：无法读取 ${WT_DIR} 的当前 HEAD，拒绝收尾" >&2; exit 1; }
  [[ "$cur" == "$HEAD_OID" ]] || {
    echo "拒绝：收尾期间 ${WT_DIR} 的实际 HEAD 已变化（${HEAD_OID} → ${cur}）。工作已被推进，请重新收尾（本脚本未做任何删除）。" >&2
    exit 1
  }
}
```

2. **在每个删除/破坏性动作之前立刻调用** `check_unchanged`：
   - `--merged`：**在 `git worktree remove` 前**（判断通过之后不能直接删）；
   - `--archive`：**在 `git tag` 前**用当前 OID 打标签；**在 `worktree remove` 前**再复核一次（若 tag 之后 HEAD 变了 → 拒绝删除并说明「标签已打，但工作已推进，请重新收尾」）；
   - **`git branch -D` 之前**也要复核（attached 情况下分支可能已被推进）。
3. **分支身份读取失败不得回退**：`:101` 的 `|| true` 吞错后回退成任务 id 当分支名 —— 改为**读取失败即拒绝**（身份未知不删东西）。
4. 复核失败时**一律不执行任何删除**（tag 若已打则保留它，但不得再删 worktree/分支）。

## H2（必须补）：工人 idle 时忙循环（成功路径不计入等待预算）

**事实（主控已实测）**：`bin/qwb-wake.sh` 的 `wait_round` 只在 **agent wait 失败**时计时。当工人已经 idle/done、而任务仍是 `running`（等主控验收）时，`herdr agent wait` **立即成功返回**，主循环就以毫秒级速度连转 —— 实测 **4.9 秒内 91 轮**账本扫描。

**规格**：

1. **无论 agent wait 成功还是失败，都要计入一轮预算**：

```bash
local t0 dt
t0="$(date +%s)"
herdr agent wait "$p" --timeout "$INTERVAL" >/dev/null 2>&1 || true   # 不让它触发 set -e，返回值不再分支
dt=$(( $(date +%s) - t0 ))
# 一轮预算 ≈ 1×interval：等待已耗掉的时间计入预算，剩余部分补 sleep
if (( dt * 1000 < INTERVAL )); then
  local remain=$(( INTERVAL - dt * 1000 ))
  sleep "$(( remain / 1000 > 0 ? remain / 1000 : 1 ))"
fi
```

2. 性质要求（这是验收点）：
   - 工人 **idle**（立即成功）时，一轮 ≈ **1×interval**（不再 91 轮/5 秒）；
   - 等待因 **pane 不存在**立即失败时，同样补 sleep（保持现有的防忙循环）；
   - 等待**耗尽 timeout**（耗时 ≈ interval）时**不再额外 sleep**（保持 G2 已修好的性质）；
   - 任何单次失败都不得让主循环退出。
