## 0. 原始意图与范围

原始意图（Rocky）：绝对禁止测试在 Herdr 的根层级（左侧 Space 列表、别的项目的 workspace）或系统目录里开东西；要创建就只能在本项目内。

### 事故（2026-10-03 约 21:00Z，已清理）

1. 一个工人执行 `rm -rf <系统临时目录>/tmp.*`，删掉了另一个工人正在跑的 `tests/smoke.sh` 的 `$TMP`。
2. smoke 的假 herdr 就放在 `$TMP/stubbin`，只靠 `PATH` 前置来遮住真 herdr。桩一消失，后面各节的 `herdr …` 全部落到 `PATH` 上的**真** `herdr`（`~/.local/bin/herdr`），而环境里 `HERDR_SOCKET_PATH` 指着真服务。
3. 结果：真 Herdr 里多了两个 Space（`wtproj`、`wtsetup`），Rocky 另一个项目的主控 workspace 里多了 6 个 tab（`t3`、`plain-id`、`named`、`reuset`、`rollback` 等），每个都起了真的 Pi 并收到了测试夹具票的提示词。

根因是测试**失效开放**：桩在就用桩，桩不在就打真服务。通配删除只是这次的触发方式；桩创建失败、`PATH` 被改、测试中途 `cd` 等都会触发同样的结果。

### 工程规格

**A. 测试失效关闭（必须做）。** 目标：`tests/` 下任何测试，无论桩是否存在，都**不可能**连到使用者正在运行的 Herdr 服务。

1. 先读清楚真 `herdr` CLI 靠什么找到服务（`HERDR_SOCKET_PATH`、`HERDR_ENV`、`--session` 等；可看 `herdr --help` 与 `tests/fixtures/herdr/wire-server.py`、smoke 里 `HERDR_TEST_SOCKET` 的用法），用**只读**方式确认哪种做法能让真 CLI 必然连接失败（例如把 `HERDR_SOCKET_PATH` 指向测试临时目录里一个不存在的路径）。验证时只许用只读查询（`herdr workspace list` 之类），且必须在已经指向死路径的环境里跑。
2. 在每个会调用 `herdr` 的测试入口最前面（建桩之前）落实这层隔离，并 `export`，使其对所有子进程生效。覆盖 `tests/smoke.sh`、`tests/*.sh`、`tests/*.py`、`tests/pi-ext.test.mjs` 中所有会直接或间接执行 `bin/qwb-*.sh` 的文件；逐个列出你检查过的文件与结论。`tests/e2e-real.sh` / `e2e-real.py` 是有意连真 Herdr 的（自建 named session），不改，但在报告里确认它们不走 default 会话。
3. 有的测试会自己设置 `HERDR_PANE_ID` / `HERDR_WORKSPACE_ID` 等假身份——这些不动；只保证「连接目标」是死的。若某个测试自己起了假服务并需要连它（如 wire-server），保持它连假服务，不受影响。
4. 再加一道显式断言：smoke 在开头（建好桩之后）检查 `command -v herdr` 解析到的就是自己的桩，否则立刻失败退出、不往下跑。

**B. 测试临时目录改到本项目内（尽量做）。** 目标：测试建的临时项目落在仓库里一个被忽略的目录下（如 `<仓库根>/.qwb-tmp/`），而不是系统临时目录。

1. `.gitignore` 加该目录。各测试的 `mktemp -d` / `tempfile.TemporaryDirectory` 改成在该目录下建。
2. 已知风险，逐条处理并在报告里写结论：
   - 临时项目嵌在本仓库里，凡是测「目录不是 git 仓库」的用例，git 会向上找到本仓库。用 `GIT_CEILING_DIRECTORIES` 挡住向上查找。
   - macOS 系统临时目录在 `/var` → `/private/var` 的符号链接下，有些用例（如物理路径规范化）可能正是靠这个符号链接成立的。改目录后这些用例如果失去了意义，要么给它们单独造一个符号链接路径，要么让它们继续用系统临时目录并写明原因。
   - `tests/smoke.sh:14-37` 的 `root-tab-missing` 窄入口用字面量（含 `TMP="$(mktemp -d)"`）切片重组脚本，改这一行必须同步改锚点。
   - 路径变长后是否触到 Unix socket 路径长度上限（约 104 字节）等限制。
3. 清理：每个测试只删自己建的那一个确切目录；`.qwb-tmp/` 本身留着。
4. 如果 B 的某一部分做不到行为不变，就只做能做的部分，把做不到的写成 `needs-decision:`，不要硬改。A 不许打折。
