### 证据边界

任务书禁止在报告外创建任何文件，因此未创建临时 Git 仓库，也未执行会创建临时文件的 `tests/smoke.sh`。独立场景在 Python/Bash 内存中运行：读取原始代码片段，替换外部 Git/Herdr 返回值，捕获实际控制流和命令参数；配置解析使用真实 `sed`/`grep`，等待使用真实 `sleep`。所有 Git 删除均为 mock，没有对现有仓库执行删除、打标签、提交或改写账本。

以下 Git 结论是**源码与命令级复现证据**，不是实际删除后的 Git 端到端证据；配置误读与延迟则是原始解析/等待代码的实际运行结果。不以修复方验收记录或冒烟断言替代证据。

## 审点 1：worktree 收尾

### 致命：detached HEAD 被替换成同名分支，验证与归档对象偏离实际工作

**位置：** `bin/qwb-worktree.sh:99-100`、`:113-128`、`:132-135`。

场景：任务 worktree 原先在分支 `task` 的提交 A 上，随后 detached checkout，并产生提交 B；原分支仍指向 A，工作区干净。脚本读到 `HEAD` 后直接令 `BRANCH=task`，没有验证这个分支是否指向 worktree 当前提交。

- `--archive` 实际发出的参数为 `git tag archive/task task`，随后 `worktree remove …/.worktrees/task`、`branch -D task`。标签保留的是 A，实际工作 B 没有被归档。
- `--merged` 检查的是 `task` 是否在主项目 HEAD 中；A 已合并而 B 未合并时，也会放行删除。该拒绝条件可被正常的 detached 操作绕过，不需要恶意输入。
- 分支删除本身的保护不能发现这种错位：被删 worktree 已经 detached，而脚本删除的是另一个具名 ref。

独立 mock 场景 `detached/archive` 与 `detached/merged` 均退出 **0**；捕获到了上述错误对象的删除命令和准备写入的成功记账行。源码没有读取 detached 提交的 OID，也没有将它用于归档/落地判断。**实际工作可能失去持久引用，清理对象后不可恢复**；本轮没有实际删除或运行 GC，不声称已观察到物理对象丢失。

### 可以不要：`--keep` 的清洁检查阻止了规范明确允许的冲突保留

**位置：** `bin/qwb-worktree.sh:20-21`、`:102-107`、`:138-145`；对照 `templates/QWBUDDY.md:79`。

规范允许“有冲突待解”的 worktree 点名保留。但脏检查在动作分流前执行，`--keep=有冲突待解` 遇到 `UU file` 会退出 **1**，到不了保留记账；普通未跟踪文件也一样。该动作本来不修改 Git，却引入了清洁前置条件，排除了规范中的有效场景。归为**可以不要的额外限制**，不要求增加状态或新功能。

### 其余独立场景结果

以下均运行原始 `99-144` 行，外部 Git 为 mock；“记账”仅捕获准备追加的文本。

| 场景 | 动作 | 退出码 | 实际控制流 |
|---|---|---:|---|
| 干净、已合并 | merged | 0 | remove → branch -d → 准备记账 |
| 干净、归档标签不存在 | archive | 0 | tag → remove → branch -D → 准备记账 |
| 干净 | keep | 0 | 无 Git 变更命令，准备保留记账 |
| 存在未跟踪文件 | merged / archive / keep | 各 1 | 无 Git 变更命令 |
| 冲突 `UU file` | keep | 1 | 无保留记账 |
| 未合并、无 remote-tracking ref | merged | 1 | 拒绝，无 Git 变更命令 |
| 创建归档标签失败（模拟标签已存在） | archive | 1 | 停在 tag，未调用 remove / branch |
| detached HEAD、同名分支存在 | merged / archive | 各 0 | 使用同名分支而非实际 detached 提交 |

补充检查：`status` 返回 128 且无 stdout 时，`:102` 的 `|| true` 也会把检查失败当作干净，mock 场景继续到归档删除命令。但真实 Git 后续是否仍能删除取决于错误原因，本轮不把它另计为已证实的数据丢失问题。

`list` 清点及派发前警告已存在；成功/废弃/例外的选择仍由主控负责，本轮不要求自动决定收尾。`prune` 仍是规范中的人工动作，不据此另报缺陷。

## 审点 2：并发唤醒与死配置

### 必须补：新写入的最大延迟结论与实际等待路径不符

**位置：** `docs/DESIGN.md:245`；`bin/qwb-wake.sh:113-114`、`:117-133`。

文档断言最大延迟为一个 `wake_interval_ms`。实际当最新派发的工人一直运行、事件等待耗尽 timeout 并返回非零时，`:130` 还会执行一次完整 `sleep_interval`。另一个工人在等待开始后完成，需要经历**等待超时 + 额外 sleep**，才会回头扫描账本。

独立构造两个未结工人 A/B，B 派发较晚。运行原始 `sleep_interval` 和 `wait_round`；Herdr mock 等待 1 秒后返回 1，`INTERVAL=1000`。从进入本轮等待到恢复扫描实测 **2.081 秒，退出码 0**。因此默认配置在该路径约为 **4 分钟加处理开销**，不是声称的最大 2 分钟。

这是本轮新增“已知限制”的事实错误；本轮未重审旧 F2 忙循环缺陷，也不要求新增并发等待架构。`templates/config.json:29-32` 的 `agent_wait_ms` 已删除，剩余两项超时都有脚本读取，这一部分无问题。

## 审点 3：配置读取

### 必须补：工人表校验仍可绕过，同名字段仍静默取错

**位置：** `bin/qwb-run.sh:60-68`；`bin/qwb-wake.sh:48-54`。

独立测试使用模板解析得到的合法 JSON，调用原始解析代码；没有运行派发或触碰真实 pane。

| 输入 | 预期 | 实际 |
|---|---|---|
| 模板，worker=`codex` | 接受 | 退出 0，接受 |
| 模板，worker=`note` | 拒绝 | 退出 1，拒绝，原复现已修复 |
| 模板，worker=`workers` | 拒绝：不在 workers 子键中 | **退出 0，接受** |
| 模板，worker=`(codex)` | 拒绝：不是实际工人键名 | **退出 0，接受** |
| 同一 JSON 压缩成单行，worker=`codex` | 接受 | 退出 1，误拒绝 |
| 顶层先放 note 对象，含同名超时和 pane 字段 | 读取 timeouts/controller | **退出 0，静默读取 note** |

根因及影响：

- `WSEC` 包含 `"workers": {` 自身，所以父键 `workers` 被当作合法工人；`:119` 后续会将它作为 `--kind workers` 传出。
- `WESC` 只转义部分正则字符，`:62` 却使用扩展正则；括号未转义，`(codex)` 匹配了真实键 `codex`，但后续传出的原始 worker 仍是 `(codex)`。
- 三个配置值仍是全文件正则加 `head -1`，没有绑定 JSON 路径。构造合法 JSON：最前面的 `note` 对象含 `agent_start_ms=7`、`wake_interval_ms=9`、`pane_id="wtest:wrong"`，实际 `timeouts` 仍为 `30000/120000`、`controller.pane_id="wtest:right"`。实测输出：

```text
START_MS=7 INTERVAL=9 PANE=wtest:wrong
exit=0, stderr=''
```

工人名修复仅挡住了原始 `note` 个例；错误配置可静默改变等待行为，并将叫醒目标指向错误 pane。单行 JSON 则暴露了未声明的排版依赖。以上归为同一个配置校验缺陷，不把增加依赖或更换解析实现当作审核要求。

## 可复核的无文件写入场景代码

在仓库根目录以 `python3 -` 执行以下代码。Git 为 mock；成功路径只打印待记账文本，既不追加文件也不执行真实 Git 变更。它读取与本轮相同的原始行段；源码变更后需重新核对行号。

```python
from pathlib import Path
import json, os, subprocess, time

def probe(name, code, extra=None):
    env = dict(os.environ, **(extra or {}))
    t = time.monotonic()
    r = subprocess.run(['/bin/bash'], input='set -euo pipefail\n' + code,
                       text=True, capture_output=True, env=env)
    print(name, 'exit=', r.returncode, 'seconds=', round(time.monotonic()-t, 3))
    print(r.stdout, r.stderr)

w = Path('bin/qwb-worktree.sh').read_text().splitlines()
stub = r'''
git() {
  printf 'CALL git %s\n' "$*" >&2
  shift 2
  case "$1" in
    rev-parse) [[ "$SCENE" == detached ]] && echo HEAD || echo task ;;
    status) case "$SCENE" in dirty) echo '?? new.txt';;
              conflict) echo 'UU file';; esac ;;
    merge-base) [[ "$SCENE" != unmerged ]] ;;
    tag) [[ "$SCENE" != tag_exists ]] ;;
    worktree|branch|for-each-ref) return 0 ;;
    *) return 99 ;;
  esac
}
'''
for scene, action in [('clean','merged'), ('clean','archive'), ('clean','keep'),
                      ('dirty','merged'), ('dirty','archive'), ('dirty','keep'),
                      ('conflict','keep'), ('unmerged','merged'),
                      ('tag_exists','archive'), ('detached','archive'),
                      ('detached','merged')]:
    setup = (f'PROJECT_ROOT=/virtual; WT_DIR=/virtual/.worktrees/task; '
             f'TASK_ID=task; ACTION={action}; SCENE={scene}; REASON=\n')
    probe(scene+'/'+action, stub+setup+'\n'.join(w[98:144])+
          '\nprintf "WOULD_APPEND %s\\n" "$line"\n')

r = Path('bin/qwb-run.sh').read_text().splitlines()
k = Path('bin/qwb-wake.sh').read_text().splitlines()
conf = json.loads(Path('templates/config.json').read_text())
shim = r'''
sed() {
  if [[ "${!#}" == /virtual/config.json ]]; then
    printf '%s\n' "$CONFIG" | command sed "${@:1:$#-1}"
  else command sed "$@"; fi
}
'''
for worker in ['codex', 'note', 'workers', '(codex)']:
    probe('worker='+worker, shim+'\n'.join(r[59:68]),
          dict(CONFIG=json.dumps(conf, indent=2),
               CONF='/virtual/config.json', WORKER=worker))
probe('minified', shim+'\n'.join(r[59:68]),
      dict(CONFIG=json.dumps(conf, separators=(',', ':')),
           CONF='/virtual/config.json', WORKER='codex'))
conf['controller']['pane_id'] = 'wtest:right'
conf = {'note': {'agent_start_ms': 7, 'wake_interval_ms': 9,
                 'pane_id': 'wtest:wrong'}, **conf}
probe('wrong-scope', shim+'\n'.join(r[66:68])+ '\n'+k[48]+'\n'+k[52]+
      '\nprintf "START_MS=%s INTERVAL=%s PANE=%s\\n" "$START_MS" "$INTERVAL" "$PANE"\n',
      dict(CONFIG=json.dumps(conf, indent=2), CONF='/virtual/config.json'))

wait_stub = r'''
INTERVAL=1000
open_items() { printf '/virtual/a.md\trunning\n/virtual/b.md\trunning\n'; }
grep() {
  case "${!#}" in
    /virtual/a.md) echo 'dispatch: 2026-09-15T00:00:00Z pane=wtest:a' ;;
    /virtual/b.md) echo 'dispatch: 2026-09-15T00:00:01Z pane=wtest:b' ;;
    *) command grep "$@" ;;
  esac
}
herdr() { command sleep 1; return 1; }
'''
probe('two-workers', wait_stub+'\n'.join(k[112:134])+
      '\nwait_round\necho SCAN_RESUMED\n')
probe('invalid-state', 'f=/virtual/pending.md; st=pending\n'+'\n'.join(k[63:68]))
```
