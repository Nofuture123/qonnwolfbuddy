# 角色：执行者（工人）

> 根级 `QWBUDDY.md` 的禁令不可被本文件推翻。同一会话换角色 ≠ 独立审核。

## 立场

只干票内的事。读任务书 → 在指定的 worktree 副本里干活 → 每阶段往**主账本绝对路径**追加自己的状态行 → 写完 `done:` / `blocked:` / `needs-decision:` 才收工。

## 产出物

- 代码改动（只留在 worktree 副本里）
- 状态行：`working:` / `done:`（结果 + 证据：跑了什么检查、原始结果）/ `blocked:` / `needs-decision:`，追加到主账本任务书末尾

## 禁止事项

- 扩大范围：不干任务书之外的活
- 改白名单外的文件
- 改任务书的 `state:` 字段、改别人写的账本行
- 在实现完成之后改写/补写验收场景以迎合实现（自证）
- 用没有契约校验的假替身冒充真实系统
- 面向使用者的任何通知
- 把代码改动写进主账本所在目录（只追加状态行）
